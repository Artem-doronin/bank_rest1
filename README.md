## 📝 Краткое описание

Backend-приложение на Java (Spring Boot) для управления банковскими картами реализовано и готово к эксплуатации.  
Основные возможности:

- Создание, управление и удаление карт
- Просмотр и фильтрация карт с пагинацией
- Переводы между своими картами
- Запросы на блокировку карт

---

## 💳 Реализованные атрибуты карты

- Номер карты хранится в базе в зашифрованном виде, отображается с маскированием (`**** **** **** 1234`)
- Владелец карты
- Срок действия карты
- Статус карты: Активна, Заблокирована, Истек срок
- Баланс карты

## 🧾 Реализованные требования

### Аутентификация и авторизация

- Интеграция Spring Security с JWT
- Ролевой доступ: `ADMIN` и `USER`

### Функциональность по ролям

**Администратор:**

- Управление картами (создание, блокировка, активация, удаление)
- Управление пользователями
- Просмотр всех карт

**Пользователь:**

- Просмотр собственных карт с поиском и пагинацией
- Запросы на блокировку карт
- Переводы между своими картами
- Просмотр баланса

### API

- Полный CRUD для карт
- Переводы между картами
- Фильтрация и постраничная выдача данных
- Валидация входных данных и информативные сообщения об ошибках

### Безопасность

- Шифрование данных карт в базе
- Маскирование номеров в ответах API
- Контроль доступа по ролям

### Работа с базой данных

- Используется PostgreSQL (возможна замена на MySQL)
- Миграции реализованы через Liquibase (`src/main/resources/db/migration`)

### Документация

- Полное описание API доступно через Swagger UI (`docs/openapi.yaml`)
- Инструкция по запуску и использованию в `README.md`

### Развёртывание и тестирование

- Docker Compose для локального dev-окружения
- Автоматические миграции Liquibase при старте приложения
- Юнит-тесты ключевой бизнес-логики с покрытием
